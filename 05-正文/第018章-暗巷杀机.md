# 第018章 暗巷杀机

傍晚申时末，天色阴沉沉的，像要下雪，冷风顺着北山坡往下灌。

宁渊在外院演武场一直待到敲过晚鼓，特意当着守在山门外那两个守备府差役的面，把外院发的新弟子腰牌挂在腰间，背着厚背刀大摇大摆地走下山道，往北坡小院的方向走去。

他太清楚这帮人的算计了。

青岚城里，守备府和镜山魏氏虽然在镜山假账案上被栖岳宗柳巡使狠狠敲打了一顿，丢了面子也吐了银子，但柳巡使昨天已经动身前往下一座城池巡查，青岚城的天，终究还是这六家说了算。

魏十二叔虽死，魏氏二房那口恶气却咽不下去；而黑市上的顾先生又悬赏五百两银子买废港带出来的古物，两家一拍即合——守备府只需在今天晚上“顺手”把北坡那一片的巡夜更夫调去南街查火烛，再把宁渊的行踪透个信，剩下的事，自然有黑市死士来替他们收拾干净。

一条没有背景的外院散修性命，死在回家的暗巷里，连波澜都掀不起半点。

宁渊步子走得很稳，既没刻意加速，也没回头张望。

拐进北坡前最后一条长巷时，天已经彻底黑透了。

这条巷子两侧原本住着十几户买了灵脉房的散修小户，这几年灵脉断绝、人去屋空，剩下一排黑洞洞、门窗破烂的烂尾空院，连盏像样的灯笼都没有。冷风穿过破窗户，发出呜呜的哨声。

宁渊刚走到巷子中段，前头十丈外的拐角阴影里，突然毫无征兆地走出来两个身穿黑衣、脸蒙黑布的高大汉子，一人手里提着一根包铁丧门棍，另一人手里端着一把上了弦的三连发精钢手弩！

与此同时，宁渊身后十丈外的巷口也传来一阵轻响，一条铁链拉着几块碎砖横着拦在了路中间，一个背着双刀的瘦削黑影慢悠悠地堵住了退路。

巷子两侧三丈高的烂尾院墙头上，还蹲着一个气息阴冷、手里捏着两枚淬毒透骨钉的矮个杀手！

前堵后截，墙上还有暗哨，整整四个养元境好手——其中正面那两个和墙头上的暗哨，气息全都稳稳压在**养元后期巅峰**甚至半步圆满！

“宁渊，把你在废港圆台底下摸出来的那两张兽皮残页，还有那块灰白石头交出来。”墙头上那个矮个杀手声音沙哑得像两块铁片在摩擦，“交出来，今天晚上我们兄弟给你留个全尸，绝不波及你屋里那个病秧子老爹。”

“顾先生倒是舍得下本钱，为了两张泡烂的废纸，居然请动了四个好手，还买通了守备府把北坡的更夫支走。”宁渊停下脚步，右手缓缓反手摸向背上的刀柄，声音冷得听不出半点慌乱，“不过，你们凭什么觉得，今天晚上能吃得下我？”

“少废话，动手！”

墙头暗哨根本不跟宁渊多扯一句，手腕一抖，两枚泛着幽蓝寒光的透骨钉撕裂空气，一左一右直取宁渊双眼！

几乎在同一息，正前方那个使连弩的黑衣汉子扣动扳机，“崩崩崩”三声脆响，三支铁箭封死了宁渊左右闪避的所有空间；身后背着双刀的杀手也如鬼魅般贴地扑了上来！

绝杀之局！

换作三天前刚打完黑水涧的宁渊，面对这种四面合围、连退路都被铁链封死的暗杀，十有八九真要交代在这条黑巷子里。

可他现在已经是**养元圆满**，胸口那枚**祖源残核**更是刚刚点亮了第一道金色细纹！

面对扑面而来的三支铁箭和两枚毒钉，宁渊没有往后退，而是脚尖猛地踩碎脚底青砖，整个人像贴地飞窜的狸猫般，不退反进地斜扑向左侧那座半塌的烂尾空院院门！

“叮！叮！”

厚背刀在他身前划出一道急促的弧线，精准无比地磕飞了两支正面铁箭，第三支擦着他肩头掠过，钉进腐朽的门框里。紧接着他肩膀一撞，“轰隆”一声撞碎那扇早就腐朽不堪的烂尾院木门，整个人滚进了伸手不见五指的空院里！

“追！别让他翻墙跑了！”墙头上那个矮个暗哨急喝一声，身形一纵顺着墙头朝空院内部扑下来，想居高临下把宁渊钉死在院子里。

正合宁渊之意！

这间烂尾空院里荒草齐腰，地面堆满了当年盖房剩下来的碎砖烂瓦，地形复杂得像个迷宫——在窄巷里他施展不开，可进了这片堆满碎石瓦砾的废院，黑灯瞎火的，谁比谁先死还不一定！

宁渊刚一翻身滚进荒草丛，根本没等另外三个杀手从破门里挤进来，右脚猛地勾起地上半块锋利的青瓦片，顺着听声辨位的本能，反手朝着墙头扑下来的黑影甩了过去！

“嗤！”

那矮个暗哨在半空中无处借力，仓促间挥手拨开瓦片，身形不可避免地顿了半息。

就是这半息！

宁渊双脚死死蹬进烂泥里，腰胯猛地发力拧转，手里七斤四两的熟铁厚背刀带着一股沉闷如雷的低啸，由下而上逆斩而起！

这一刀，他动用了昨夜刚刚借残核第一道金色细纹领悟出的《叠息劲》第三重暗劲——一息沉气、二息叠力、三息劲透刀背！

“当——！！”

矮个暗哨仓促间架起双臂护腕格挡，可那股层层叠加的恐怖暗劲顺着护腕直接透进了骨头里！

“咔嚓！”

两声清脆的断骨声几乎同时响起！矮个暗哨惨叫一声，两条小臂齐腕而断，整个人像个沙袋一样从半空中直直砸进荒草丛里，胸口肋骨又被宁渊紧随而至的一记膝撞踩断三根，当场喷出一口黑血昏死过去！

“老四！！”

刚冲进破门的另外三名杀手吓得魂飞魄散——一个养元后期巅峰的好手，照面不到两息就被生生废了！

“点子扎手！结阵围杀！”使丧门棍的壮汉怒吼一声，浑身养元后期巅峰的元力轰然爆发，挥起包铁丧门棍如疯虎般砸向宁渊面门；后面使双刀的瘦削杀手则贴着墙根绕向宁渊左侧死角！

宁渊不退反进，顶着阴冷的夜风大口呼吸。

随着剧烈搏杀，夜空下北坡废弃灵脉里残留的那一丝丝阴冷浊气被他顺着呼吸牵引过来，胸口的祖源残核微微发热，瞬间将浊气滤成滚烫精纯的先天灵气反哺经脉，让他每一刀劈出去都力大无穷、丝毫不见衰竭！

“滚开！”

宁渊左手抓起一把烂泥沙土劈头盖脸扬向使双刀的杀手眼睛，右手厚背刀顺势横扫，硬生生磕开那根砸下来的包铁丧门棍！

“砰！”

丧门棍剧烈震颤，震得那壮汉虎口当场飙血！还没等他喘过气，宁渊脚下已经欺近他怀里半步，一记沉肩肘击狠狠撞在他心口膻中穴上！

“咔！”

壮汉胸骨塌陷，像虾米一样弓着身子倒飞出去，撞塌了半截土墙，抽搐两下便断了气。

前后不到十息，四名杀手两死一废！

剩下那个使连弩的和使双刀的汉子彻底胆寒，哪里还敢再战？发一声喊，丢掉兵器转身就往破门外逃窜！

宁渊哪会放虎归山？他反手抓起地上死去壮汉掉落的半截铁棍，灌注养元圆满真元狠狠掷出——

“噗嗤！”

铁棍如标枪般贯穿了跑在最后的连弩手后背，将他死死钉在院门外的青石板上！至于那个使双刀的，借着夜色拼命翻过巷尾矮墙，一瘸一拐地逃进了黑夜里。

宁渊没有盲目追出巷外，而是快步走回荒草丛里，一脚踩住那个双臂骨折、正在地上痛苦呻吟的矮个暗哨胸口，厚背刀冰冷的刀尖抵在他咽喉半寸处：

“说，除了顾先生悬赏五百两，今晚是谁通知守备府把北坡更夫支走的？行踪又是谁卖给你们的？”

矮个暗哨疼得冷汗直冒，看着宁渊眼底毫无波澜的杀意，心理防线彻底崩溃，哆哆嗦嗦地吐出几个字：“是……是魏家二房的管事！还有……守备府里姓周的捕头！他们拿了顾先生二百两茶水钱，说只要把你做掉在北坡暗巷里，明天一早守备府直接按‘黑市仇杀’给你销案……”

宁渊眼神彻底冷了下来。

果然是官匪勾结、层层分赃。上面的大人物体面地坐在高堂上喝茶，底下的差役和黑市杀手拿着茶水钱在暗巷里杀人销案。

他没再多问，手腕一沉，利落地结果了这个暗哨的性命，随后从这几个死士身上摸出大约四十两散碎银票和两瓶劣质金疮药，又把现场稍微清理了一下，这才拎着滴血的厚背刀走出烂尾空院。

刚迈出院门两步，宁渊的脚步突然顿住了。

巷子北头、自家小院外二十丈处的一棵老槐树阴影底下，不知什么时候静静站着一个人。

月光从云缝里漏下来一点，照亮了那张熟悉的少年脸庞——**陆昭**。

他站在阴影里一动不动，既没有靠近，也没有拔刀。刚才院子里打得天翻地覆、惨叫声传出半条巷子，陆昭明明就在二十丈外，却至始至终没有露面搭过一把手。

“你什么时候来的？”宁渊擦去刀身上的血水，插回刀鞘，平静地走过去。

陆昭沉默了两息，眼神在夜色里显得有些飘忽，低声道：“刚到巷口。听见里头没动静了，正准备进去看看。”

宁渊停在他面前三步处，借着微弱的月光仔细打量了一番发小——陆昭的衣领干干净净，鞋帮上却沾着几粒只有在南郊荒坟林才有的黑灰土，而他袖口底下隐隐透出来的那股气机，居然沉重得隐隐逼近了养元圆满！

才短短几天没见，一个刚升入外院的养元中期弟子，怎么可能无声无息地摸到圆满门槛？

“没事了，几个不长眼的黑市毛贼，已经解决了。”宁渊没有拆穿他，只是伸手拍了拍陆昭的肩膀。

指尖触碰到陆昭肩头衣料的那一瞬间，宁渊胸口那枚一直安安静静的**祖源残核**，竟然毫无征兆地猛然发烫了一下，传出一股极其轻微、却带着强烈排斥感的刺痛！

仿佛陆昭的皮肤底下，正蛰伏着一缕让残核极度厌恶的冰冷异种气息。

宁渊手掌不动声色地收了回来，心里却瞬间掀起了惊涛骇浪。

陆昭……身上沾了什么脏东西？
