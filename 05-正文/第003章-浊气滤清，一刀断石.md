# 第003章 浊气滤清，一刀断石

黑水涧位于青岚东北三十里外，两山夹一沟，终年不见阳光。

三十余名试录少年刚一踏入谷口，就闻到了一股浓烈的血腥味。谷底的溪水不知何时变成了暗红色，岸边几株枯树上缠满灰白色的雾气，正是昨夜从旧河蔓延过来的“浊潮”。

“两人一组，别离开涧底十丈之外！”赵观山站在谷口高岩上高声喝道。

宁渊与陆昭一前一后沿着乱石滩推进。没走出一里，前方乱草丛中突然传出一声低沉的嘶吼，一头浑身覆满灰褐色岩石甲壳、体格壮如牛犊的**石甲獾**猛地扑了出来！

“不对！这畜生眼睛是红的！”陆昭脸色一变，拔刀横挡，“它吸了浊潮发狂了，力量起码比寻常石甲獾强出三成，相当于半步养元圆满！”

话音未落，石甲獾四蹄刨碎乱石，像一堵移动的铁墙般狠狠撞来！

陆昭咬牙劈出一刀，青纹钢刀砍在石甲獾肩甲上，竟溅起一串刺眼的火星，震得他虎口发麻、连退五步，嘴角溢出一丝鲜血。

“宁渊，退！往谷口撤！”陆昭大吼。

宁渊却眼神一凝——谷口方向的必经窄道上，不知何时滚落下来几块半人高的巨石，隐约还能看见岩壁上方闪过一抹锦衣衣角！

魏承礼竟趁着乱局，在后面暗中推石封死了他们的退路！

“退不了了！”宁渊低喝一声，反手握紧旧铁刀，脚下踩着《青溪归元功》的步法猛地斜刺里扑上，替陆昭挡下石甲獾的二次扑击。

轰！

一声闷响，宁渊只觉得左臂像被铁锤砸中，整个人倒飞出去，重重撞在湿滑的岩壁上。更致命的是，随着剧烈喘息，周围弥漫的灰白浊潮顺着口鼻疯狂灌入他的肺腑！

“呃啊——！”

狂暴阴冷的浊气如无数钢针般扎进经脉，原本稳固的养元中期气海瞬间濒临崩溃。石甲獾嗅到血腥味，发出一声暴戾的咆哮，低头露出两根森白的獠牙，朝着动弹不得的宁渊狂奔而来！

“宁渊！”陆昭拼命扑过来救援，却被飞溅的乱石绊了一步，眼看已经来不及。

死亡的阴影当头罩下！

就在宁渊经脉即将被浊气撑爆的千钧一发之际，贴在他胸口布囊里的那枚灰白碎晶——**祖源残核**，突然发出了一声清越到极致的嗡鸣！

一股难以言喻的吸力骤然自他胸口炸开。

原本在他体内横冲直撞、令人经脉寸断的灰白浊潮，在触及那枚碎晶的瞬间，竟仿佛遇见了天敌般剧烈震颤起来！杂质、淤毒、暴虐煞气被碎晶毫不留情地吞噬剥离，化作一丝微弱的黑烟消散；而剩下的，是一股**纯粹、温润、精纯到令人战栗的先天灵气**，如决堤春水般轰然倒灌进宁渊的气海！

咔嚓！

体内仿佛有什么无形的枷锁被一冲而碎！

干涸的气海瞬间暴涨一圈，原本稀薄的元力在精纯灵气的冲刷下凝练了数倍，**养元后期**的门槛应声而破！不仅如此，残核滤清后的灵气余韵顺着双臂经脉奔涌而下，原本震裂的虎口与酸痛的筋骨瞬间恢复了全部气力！

“原来……这就是残核的本事……”

宁渊猛地睁开双眼，瞳孔深处闪过一抹锐利如刀的精光。

石甲獾的血盆大口已经近在咫尺，腥臭的恶风扑面而来！

宁渊不退反进，左脚狠狠踏碎地面青苔，体内刚刚突破的养元后期元力狂涌而出，按照父亲昔日曾提过一遍、自己苦练千百遍却一直差一口气的爆发法门——《叠息劲》，一息三叠，尽数压进右手旧铁刀中！

“给我断！”

刀锋化作一道冷冽的白练，没有砍向坚硬的背甲，而是顺着石甲獾张开的下颚与颈甲缝隙，自下而上斜撩而过！

噗嗤！

暗红色的鲜血冲天而起！那把布满缺口的旧铁刀虽在最后一刻“铛”地一声崩断了半截刀尖，却已将整头狂暴石甲獾的头颅连同颈骨一刀两断！

庞大的兽躯轰然倒地，滑出三丈远，刚好撞在魏承礼等人推下的封路巨石上，震落一阵碎石尘埃。

死寂。

原本正准备跑过来捡尸的陆昭僵在原地，手里的青纹钢刀差点脱手。而隐在十丈外高岩后的魏承礼，更是脸色煞白，像是见了鬼一般猛地缩回身子。

养元中期，一刀斩杀吸了浊气发狂的一阶巅峰妖兽？！

宁渊喘息着站起身，甩掉断刀上的兽血，目光冷冷穿过雾气，直直锁定了高岩后那片衣角消失的方向。

他低头看了一眼胸口重新归于沉寂的布囊，心里第一次生出无比清晰的野望：

“连这口被世人当成毒药的浊潮，我都能滤成灵气……这世道，凭什么不让我争一争？”
