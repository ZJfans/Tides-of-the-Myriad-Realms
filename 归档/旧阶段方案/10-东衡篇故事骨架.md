# 《诸天回潮》东衡篇故事骨架

> 文档状态：【已确认，可微调】前三百章总体方向、地图扩张顺序与阶段终点；【候选】【待验证】各阶段精确章数、具体事件、对手、资源、突破节点与跨陆方式。
>
> 本文件负责规划宁渊从青岚出发、走过东衡并第一次跨出东衡的故事脊柱。全书四大篇结构见`阶段成果/13-全书故事脊柱.md`。本文件不是逐章大纲，不无声覆盖世界规则、人物关系或残核边界。

## 一、东衡篇的一句话

> 异常回潮在预测之外提前触及东衡，宁渊从青岚镇出发，在北山获得祖源残核，沿局部异常逐步走过临河府、东垣边地和中衡原，最终参与恢复一条古代外路；通道因十二陆旧网络与断裂坐标发生偏移，把他送往另一片更早迷失的大陆。

东衡篇不是“离开新手村以前的准备期”，而是全书第一个完整大篇。它必须建立宁渊与家人、青岚和东衡的真实联系，完成从个人资源困境到大陆生存问题的自然升级。

## 二、三百章阶段终点

### 【已确认，可微调】阶段终点

- 宁渊在完整经历东衡地方、府域、区域与大陆级成长后，才参与东衡第一次有效对外重联；
- 东衡篇末，宁渊作为少数先行者之一跨出东衡，却意外进入前四片失陆中的一片；约三百章只是当前节奏尺，具体境界和章节保持【候选】【待验证】；
- 跨陆是东衡篇结局和迷失大陆篇开端，不是宁渊永久抛弃家园；
- 偏航证明古代十二陆交通网络仍有残存节点，但不等于七陆通道已经恢复；
- 东衡尚未回归苍梧主体，原通道也不能立刻长期稳定运行。

### 为什么不更早或更晚

若两百章以前离开，东衡容易沦为扩大版新手村，失陆文明、家园情感和内部利益结构都没有充分建立。若拖至四五百章以后，七陆、古十二陆和大世界探索的承诺兑现过慢，地方冲突也容易重复。

因此采用：

> 前约二百五十章完成东衡内部成长与真相推进，后约五十章完成第一次失陆重联。

精确章数只是节奏尺，不是不可调整的硬性数字。

## 三、前三百章的总因果链

> 预测之外的局部异常
> → 宁渊在正常现实行动中卷入北山变化
> → 主动接近七年前事故边缘并获得祖源残核
> → 有限收益改变个人处境
> → 北山新资源进入临河府利益竞争
> → 多地同类异常证明变化不止北山
> → 续界支路重新获得输入，东衡旧分配受到冲击
> → 宁渊进入中衡原，接触大陆断联与撤离证据
> → 关键旧路出现短暂恢复可能
> → 东衡内部围绕是否重联、由谁控制及谁先跨越发生冲突
> → 宁渊跨出东衡，却落入另一片失陆，确认古十二陆旧网络并未彻底死亡。

## 五、第一阶段：北山潮起（约1—50章）

### 阶段目标

完成开篇发动、宁渊人物建立、第一次局部异常、祖源残核获取和第一份现实兑现。

### 1. 正常行动被异常打断（约1—10章）

- 宁渊为修炼资源或稳定渠道，参加一项发生在北山开放区域的合法行动；
- 可使用外部药地、正常山道、清理兽患或其他已有地方秩序能够支持的行动；
- 雾谷维护区在七年前事故后仍然全面封锁，开篇不能公开拆除事故旧阵；
- 本轮异常回潮没有按传统经验逐步显露，最先以一个局部规律失效触及北山；
- 普通参与者只会按阵路失误、药场异变、兽群异常或地下潮压解释；
- 宁渊凭自身判断获得继续行动的资格或第一份小收益，尚未获得残核。

开篇具体采用采药、清兽、护送、外围阵务或其他行动，保持【候选】【待验证】，由下一轮前30章规划和场景测试决定。

### 2. 进入事故边缘（约11—30章）

- 异常逐渐影响北山的兽群、资源点、山道或封锁区边缘；
- 宁渊因已经承担的任务、救人、保住资源或争取机会继续深入，不以调查叔叔为直接目的；
- 宁川的旧伤、回避和七年前记录只提供有限警示，不能成为藏宝图；
- 宁渊通过行动接触仍留在北山的同一枚祖源残核；
- 残核不呼唤、不认主、不解释自身，也不主动替他解危；
- 第一次作用只处理一份现场真实存在、普通修士不能直接利用的微弱源性输入。

残核的具体输入、介质、输出和代价继续标记为【候选】【待验证】。

### 3. 第一次现实兑现（约31—50章）

- 宁渊利用有限收益改变一场实际危机或资源结果；
- 返回正常社会后，新资源、开放范围、收益归属和事故责任进入现实争议；
- 地方势力围绕北山价值行动，而不是围绕宁渊无故打压；
- 宁渊获得稳定资源、后续行动资格、收入渠道或地方地位中的一项核心回报；
- 阶段末只证明北山异常不是普通偶然，不揭示回潮、失陆和祖河真相。

## 六、第二阶段：临河争流（约51—110章）

### 阶段目标

把个人机缘转化为地方资源竞争，让宁渊在比青岚更大的修炼社会中完成第一大境成长。

### 核心冲突

北山旧资源恢复价值后，府城、地方家族、宗门外支、商行和散修队伍必须重新判断：

- 原有处置权是否继续有效；
- 新投入和旧维护应如何计算；
- 开放名额和危险责任由谁承担；
- 新资源先用于地方生计、修炼培养还是上缴续界体系；
- 异常区域应封锁、开发还是持续观察。

竞争者可以强势、自私或傲慢，但必须拥有真实资源目标和独立行动，不得全员围绕主角送经验。

### 宁渊的阶段变化

- 初步掌握残核唯一核心作用的第一种稳定用法；
- 明确看见转换损耗、承载上限与排废代价；
- 经历同层修士的资源竞争和正式战斗；
- 建立少量能够贯穿后续的人际关系，而非一次性队友名单；
- 约在第90—110章建立灵轮，兑现第一卷从养元走向稳定循环的承诺；
- 获得离开临河府、前往东垣更大区域的现实理由。

阶段末，临河府确认其他地区也出现无法用常规潮动解释的同类异常。

## 七、第三阶段：东垣换脉（约111—170章）

### 阶段目标

证明东衡是一块完整大陆，让回潮第一次进入区域政治、资源运输和续界工程。

### 核心冲突

异常输入使部分已经关闭或降格的续界末端重新产生价值：

- 中心希望恢复统一调度，以维持大陆整体循环；
- 边地认为自己长期承担衰退代价，新资源不应再次被抽走；
- 地方势力试图在新规则确定前占据资源、路线与技术优势；
- 普通修士和小势力第一次拥有进入旧资源区的上升机会；
- 新输入同时带来不适配、污染、异兽返性或旧阵失控。

续界工程不能被写成纯粹邪恶制度。中心调度真实维持了东衡存续，边地承担的代价也真实存在。

### 宁渊的阶段作用

残核只能帮助处理某个关键节点中的极少量特殊输入，不能代替工程、强者和真实资源。宁渊的价值来自判断、转换能力与实际经历的组合，不是一个人修复地区。

约第170章，宁渊确认北山只是最早变化的节点之一，东衡多地正在出现同源异常。

## 八、第四阶段：东衡旧史（约171—235章）

### 阶段目标

从“异常遍及大陆”推进到“东衡与外界存在被切断的历史联系”。

### 历史证据

宁渊进入中衡原并接触掌握续界工程的高层，只能逐层获得以下事实：

1. 东衡是一套与外部断联的大陆循环；
2. 古代确实存在撤离、节点关闭和资源集中；
3. 不同传承对东衡是被遗弃、被保护还是主动断开存在冲突版本；
4. 外部世界可能没有全部毁灭。

这一阶段仍不能完整公开玄初祖源、九条祖河、上游截流、两名异族和本土强者的历史责任。

### 关于“死境”或破碎空间

【候选】【待验证】用户提出的死境、死亡世界残片或破碎空间，更适合在本阶段作为一次大型旧节点事件进行测试，而不是作为青岚日常或第一章随机副本。

若采用，必须满足：

- 只在异常潮压、旧界路或极端薄弱节点出现；
- 不是随处掉落的宝库；
- 主要作用是带来外界、撤离或历史层证据；
- 多数区域残破、危险且无法长期维持；
- 不把道路失真和土地消失重新写成普通人的日常。

宁渊可在约第210—240章形成个人神通，获得参与大陆级事件的能力，但仍不是东衡顶层。

## 九、第五阶段：失陆重联（约236—300章）

### 阶段目标

完成东衡第一次有效对外连接，并以通道偏航证明另一片失陆同样可能保有山河、生命或文明痕迹。东衡与苍梧主体七陆的直接接触留给下一大篇完成。

### 核心冲突

异常潮流令某个关键旧节点出现短暂恢复可能。东衡内部围绕五个问题分裂：

1. 外界是否仍然存在；
2. 重联是否会破坏东衡脆弱的内部循环；
3. 通道应由谁控制；
4. 谁拥有第一批跨越资格；
5. 若外界强于东衡，应选择公开、交易、防备还是继续封闭。

不同立场都必须拥有真实理由：求取资源、避免入侵、垄断机会、保护大陆循环、争取边地自主或维护中心秩序。

### 重联边界

- 祖源残核只处理通道中的一个局部不适配问题；
- 真正重联依靠东衡现存工程、高层修士、大量资源和异常潮机；
- 宁渊不能单人打开通道或修复东衡；
- 通道前期短暂、昂贵且不稳定，不能立刻支持整陆回归和大规模迁徙；
- 通道首先接上另一片失陆，不立即支持东衡与七陆直接通行；七陆多数人仍认为东衡已经毁灭，这一认知冲突留待迷失大陆篇结束后爆发。

### 第三百章阶段画面

【已确认，可微调】宁渊穿过旧路后，没有抵达预想中的苍梧主体，而是看见另一片同样残存着山河、遗迹乃至生命痕迹的失落大陆。

具体抵达地点、当地文明状态和失陆身份保持【候选】，但阶段意义锁定：

> 东衡不是唯一没有彻底死去的失陆。

## 十、修炼成长节奏

以下为【已确认，可微调】的成长区间，不是逐章硬指标：

| 阶段 | 建议状态 | 叙事作用 |
|---|---|---|
| 开篇 | 养元四重候选 | 有基础、有行动力，但资源与战斗经验有限 |
| 约30章 | 养元中段出现清楚进步 | 第一次机缘改变现实成长速度 |
| 约50—70章 | 养元后段或接近后段 | 有资格参与临河层级争夺 |
| 约90—110章 | 建立灵轮 | 完成第一卷公共成长承诺 |
| 约120—200章 | 发展灵轮循环与个人战法 | 能够跨区域行动并承担更大责任 |
| 约210—240章 | 形成个人神通 | 有资格进入大陆级事件，但不是顶层强者 |
| 东衡篇末【候选：约300章】 | 境界待后续校准 | 具备参与大陆级外路行动的资格，却先进入另一片更早迷失的大陆 |

每次突破都必须由真实输入、宁渊自身修炼、实际行动和战斗验证共同完成。残核只提供特殊转换机会，不发放境界。

## 十一、信息揭示阶梯

| 阶段 | 宁渊与读者可以知道 | 仍然隐藏 |
|---|---|---|
| 1—50章 | 北山异常与七年前事故存在某种联系 | 异族、残核身份、失陆、祖河 |
| 51—110章 | 异常开始改变临河资源，其他地方可能也有变化 | 东衡真实结构、外界现状 |
| 111—170章 | 东衡多地同源异常；续界工程在集中有限循环 | 东衡被放弃的全貌、七陆现状 |
| 171—235章 | 东衡与外界断联，古代发生过撤离，外界可能尚存 | 九潮、截流、玄初源爆完整真相 |
| 236—300章 | 东衡是苍梧失陆之一；七陆仍有完整文明 | 上游截流全貌、祖源战争与三名强者真相 |

约一百章以后出现古史疑点，不等于约一百章便公布东衡失陆。完整确认应当由实际跨陆事件完成。

## 十二、长期人物线在前三百章的投放上限

### 宁川与叔叔

- 宁川承担父子关系、旧伤、保护和隐瞒压力；
- 叔叔只通过名单、无尸体、记录缺页和宁川回避留下痕迹；
- 第一异族不成为前三百章持续追杀宁渊的主要反派；
- 宁渊获得残核不等于立刻查明叔叔真相。

### 本土强者

- 只允许出现有限烙印效果和未完成修炼结构；
- 不持续交流、不传授完整功法、不解释宇宙；
- 其参与截流体系的历史责任不在东衡篇完整揭晓。

### 第二异族

- 不要求在东衡篇公开异族身份；
- 感情线、立场变化和终极牺牲不提前挤入前三百章主轴；
- 若以普通身份提前进入故事，也必须先作为独立人物成立，且具体方案仍待验证。

## 十三、前三百章明确禁止

- 不把三百章写成持续调查北山旧案；
- 不让宁渊长期停留青岚或临河府；
- 不让东衡成为只有一镇一府的空壳大陆；
- 不在开篇拆除七年前事故中的封锁旧阵；
- 不用精确潮期倒计时替代已经留白的世界时间规则；
- 不让七条被压弱祖河同时恢复；
- 不让宁渊依靠残核单人修复东衡或打开跨陆通道；
- 不在东衡篇完整公开九河截流和玄初大战；
- 不让第一异族、本土大势力或第二异族终局抢占前期主线；
- 不把死境写成随机刷新、遍地古宝的副本系统；
- 不让宁渊离开东衡后失去家园牵引。

## 十四、下一步

下一阶段不是正式写第一章，而是从本骨架反推：

1. 前30章的主因果链与三个阶段性兑现；
2. 宁渊进入北山开放区域的正常行动；
3. 突然异常具体打乱什么既有经验；
4. 第一次接触残核的输入、输出、限制与现实收益；
5. 第1章、第3章、第10章、第30章各自必须交付什么；
6. 在上述结构成立后，再进行第四轮开篇场景测试。

在前30章结构确认前，不直接写正式第一章，也不把采药、猎兽、拆解外围阵法或其他入口升级为正式设定。
