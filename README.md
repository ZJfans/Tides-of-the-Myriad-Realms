# 诸天回潮（Tides of the Myriad Realms）

> **大宇无情，因果难销；寂季将尽，诸天回潮。**

一个在灵气枯竭、阶层固化的末法时代苦苦求存的流放后裔少年，凭一枚能“滤尽万浊、提纯真灵”的残缺祖核，从青岚城外的一座破旧灵脉小院出发，在七年前的旧阵迷局与宗门倾轧中杀出血路，随诸天回潮步入大争之世。
