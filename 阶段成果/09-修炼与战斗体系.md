# 《诸天回潮》修炼与战斗体系

> 文档状态：【已确认，可微调】体系原则、前三境底座、人兽对应、战斗判断与前期等级口径；【待设计】灵轮、神通的进一步细分及后续境界。
>
> 文件职责：只维护跨人物、跨卷通用的修炼与战斗规则，不保存宁渊开篇参数、候选功法、兵器、资源名或残核首次效果。世界能量链以`../02-大世界规则.md`为权威出处；所有前期执行候选统一在`../04-作品原型工作台.md`维护。

## 一、设计原则

### 1. 境界硬刻度，其他体系软识别

【已确认，可微调】人物成长必须有清楚刻度，前期使用：

> 养元 → 灵轮 → 神通

养元保留一至九重。灵轮、神通只确定必要边界，神通之后保持【待设计】，不为完整感继续堆叠境界。

功法、术法、丹药、药材、兵器、阵法与血脉不共用“凡、灵、天、圣、源”式万能品阶。社会可以使用基础法、家传法、宗门真传、古法残篇，或凡兵、灵兵、古器等粗略称呼，但它们只是便于交易和传承的地方分类，不是覆盖诸天的绝对等级。

人物与妖兽的实力必须保持直观。人类使用“境界＋重数”，妖兽使用“一至九阶”；两者提供读者能够快速判断的常规威胁对应。软识别只适用于功法和物品，不等于取消人物、妖兽的明确等级。

### 2. 熟悉表层，独特底层

前期读者直接接触灵气、元力、功法、术法、药材、丹药、兵器、阵法、资源与突破。原创性主要来自寂行与回潮改变这些熟悉事物的运行条件：旧法可能因输入不足沉寂，也可能在新输入出现后重新有用；同一药材、古器和阵法在不同时代的实际价值并不固定。

> 境界告诉读者人物走到了哪里；能力、代价和来历告诉读者不同修士为什么彼此不同。

### 3. “源”是性质，不是普通品阶

【已锁定】能量关系为：

> 源 → 界息 → 源气 → 灵气 → 修士元力

“源”接近世界根本的输入与规则，不是“天阶之上的源阶”。祖源残核也不是一件可放进日常交易表的“源级宝物”。普通低阶修士主要使用灵气与自身元力；源性事物体现的是作用层级和力量性质不同，不只是威力更大。

### 4. 所有能力必须闭环

任何修炼、术法、阵法、器物或残核效果，都必须能够回答：

> 输入从哪里来 → 如何转化 → 输出是什么 → 损耗和排废去哪里 → 谁来承载、上限在哪里。

动态环境只会改变输入量、适配条件、效率与维护成本，不会取消能量守恒。

### 5. 各体系的识别方式

- **功法：** 看修炼对象、运行路线、效率、适应环境、传承完整度和上限；
- **术法：** 看作用、消耗、掌握程度、发动条件和实战结果；
- **丹药与药材：** 先看用途、药性和实际品质；
- **兵器：** 看材质、承载能力、特性、来历和实际战绩；
- **阵法：** 看用途、覆盖范围、运行条件、消耗和维持成本；
- **血脉：** 前期不设统一品阶，以具体能力、觉醒条件和代价呈现；
- **源性事物：** 不设普通等级，不进入日常交易品阶。

## 二、前期三个境界

### 养元

修士吸收经过本世界山川与生命过滤的灵气，以功法炼成带有自身生命特征的元力，并逐步淬炼肉身、经脉与承载能力。元力主要留存在血肉和经脉中，可贯入拳脚、兵器或基础术法。

养元一至九重是前期最直观刻度，综合反映可稳定容纳的元力、经脉承载、炼化效率与控制程度，不等同于九个自动赠送技能的关卡。同重胜负仍取决于底子、手段、装备与判断。

### 灵轮

修士在体内建立相对稳定的元力周转，不再只靠“吸收—储存—耗尽”的一次性循环。灵轮能够回收部分散逸元力，提高持续输出和恢复效率，但仍需要外部输入，不是永动机。

前期只需让读者看清：灵轮修士能更稳定地让元力离体、连续使用术法并维持护身；具体轮数、分层和突破仪式【待设计】。

### 神通

修士把长期修炼的力量性质、术法经验和个人理解固定进自身循环，形成具有个人特征、能够反复发动并继续成长的能力。神通不是随机觉醒，也不是到境界自动领取。

神通之后的境界、寿命和跨界规则均【暂不处理】。

## 三、人类与妖兽的对应等级

### 1. 总体口径

【已确认，可微调】人类修士使用境界名与境内重数，妖兽使用一至九阶：

| 妖兽等级 | 常规对应修士 | 当前处理 |
|---|---|---|
| 一阶妖兽 | 养元境 | 前期主要活动层级，需要明确使用 |
| 二阶妖兽 | 灵轮境 | 可作为前期明显上限与重大威胁，内部细分待设计 |
| 三阶妖兽 | 神通境 | 暂只保留概念接口 |
| 四至九阶妖兽 | 对应后续大境界 | 只保留九阶总框架，不提前创造境界名称与生态百科 |

一至九阶是妖兽生命层次和常规威胁的纵向尺度，不是让丹药、功法、兵器和阵法一起套用的万能九级表。

### 2. 一阶妖兽的前期细分

为方便养元阶段实战判断，一阶妖兽暂按初段、中段、后段区分：

| 一阶细分 | 常规对应 |
|---|---|
| 一阶初段 | 养元一至三重 |
| 一阶中段 | 养元四至六重 |
| 一阶后段 | 养元七至九重 |

这种对应表示通常正面威胁，不是绝对胜负公式。妖兽肉身、速度、毒性、天赋与环境优势，修士的功法、兵器、术法、准备和配合，都会改变结果。受伤、幼年、返性、畸变与异常污染也必须单独计算。

### 3. 妖兽、灵兽与异兽

【已确认，可微调】三种称呼不建立三套等级：

- **妖兽：** 野外具有超凡力量、对人存在潜在威胁的兽类，是前期最常用总称；
- **灵兽：** 被驯养、契约，或性情相对稳定、能够与人长期共处的兽类；
- **异兽：** 出现返性、畸变、陌生古性或其他特殊变化的描述性称呼，不是独立生命等级。

三者共用一至九阶。某只兽可以因处境被不同人物称为妖兽或灵兽，但不会因此改变阶位。

### 4. 其他体系如何保持直观

- **功法：** 可用基础法、家传法、宗门真传、古法残篇等社会称呼，同时必须说明适用环境、传承完整度和修炼上限；
- **术法：** 可用基础术法、上乘术法、秘术、神通等粗略称呼，实际强弱仍看消耗、条件、掌握和效果；
- **丹药与药材：** 以用途为先，同一种资源可按药性和成色称次品、合格、上等，不将所有丹药统一套入九阶；
- **兵器：** 前期可用凡兵、灵兵、古器等通俗分类。凡兵、灵兵重在承载与特性，古器重在来历与时代条件，古器不保证当前一定更强；
- **阵法：** 以用途、覆盖范围、运行条件、消耗和维护成本判断，不急设统一品阶；
- **源性事物：** 不进入日常等级表，祖源残核不能被称为普通“九阶宝物”或“源级神器”。

这些称呼为读者提供快速印象，但正文最终要以实际表现校正标签。

## 四、特殊转换能力进入修炼体系的接口

任何能够处理源性、异质或不适配输入的特殊器物，都不能绕过本文件的通用规则：

1. 必须有现实输入，输出少于有效输入，并产生损耗、废质或承载压力；
2. 输出不自动等于修为，仍需由身体、功法、兵器或阵法完成承接与地方化；
3. 低阶修士不能直接承接过于纯粹或层级过高的输出；
4. 特殊器物不能自动提示、发布任务、替代修炼、代打或无条件护主；
5. 触发条件、单次容量、恢复和超限后果必须能够在场景中验证；
6. 个别器物的具体输入、输出和首次效果，不在本文件定义。

祖源残核的候选合同统一见`../04-作品原型工作台.md`。
