# 《诸天回潮》修炼与战斗体系

> 文档状态：【已确认，可微调】体系原则、前三境底座、人兽对应、战斗判断、前期等级口径、灵轮一至九重与灵轮突破最小规则；【待设计】神通的进一步细分及后续境界。
>
> 文件职责：只维护跨人物、跨卷通用的修炼与战斗规则，不保存宁渊开篇参数、具体功法、兵器、资源名或残核场景参数。世界能量链与残核根本物理以`../02-大世界规则.md`为权威出处；宁渊前期参数以及残核、种子功法候选统一在`../04-作品原型工作台.md`维护。

## 一、设计原则

### 1. 境界硬刻度，其他体系软识别

【已确认，可微调】人物成长必须有清楚刻度，前期使用：

> 养元 → 灵轮 → 神通

养元与灵轮都采用一至九重，使人物、宗门弟子和妖兽威胁能够直观比较。神通只确定必要边界，神通之后保持【待设计】，不为完整感继续堆叠境界。

功法、术法、丹药、药材、兵器、阵法与血脉不共用“凡、灵、天、圣、源”式万能品阶。社会可以使用基础法、家传法、宗门真传、古法残篇，或凡兵、灵兵、古器等粗略称呼，但它们只是便于交易和传承的地方分类，不是覆盖诸天的绝对等级。

人物与妖兽的实力必须保持直观。人类使用“境界＋重数”，妖兽使用“一至九阶”；两者提供读者能够快速判断的常规威胁对应。软识别只适用于功法和物品，不等于取消人物、妖兽的明确等级。

### 2. 熟悉表层，独特底层

前期读者直接接触灵气、元力、功法、术法、药材、丹药、兵器、阵法、资源与突破。原创性主要来自寂行与回潮改变这些熟悉事物的运行条件：旧法可能因输入不足沉寂，也可能在新输入出现后重新有用；同一药材、古器和阵法在不同时代的实际价值并不固定。

> 境界告诉读者人物走到了哪里；能力、代价和来历告诉读者不同修士为什么彼此不同。

### 3. “源”是性质，不是普通品阶

【已锁定】能量关系为：

> 源 → 界息 → 源气 → 灵气 → 修士元力

“源”接近世界根本的输入与规则，不是“天阶之上的源阶”。祖源残核也不是一件可放进日常交易表的“源级宝物”。普通低阶修士主要使用灵气与自身元力；源性事物体现的是作用层级和力量性质不同，不只是威力更大。

### 4. 所有能力必须闭环

任何修炼、术法、阵法、器物或残核效果，都必须能够回答：

> 输入从哪里来 → 如何转化 → 输出是什么 → 损耗和排废去哪里 → 谁来承载、上限在哪里。

动态环境只会改变输入量、适配条件、效率与维护成本，不会取消能量守恒。

### 5. 各体系的识别方式

- **功法：** 看修炼对象、运行路线、效率、适应环境、传承完整度和上限；
- **术法：** 看作用、消耗、掌握程度、发动条件和实战结果；
- **丹药与药材：** 先看用途、药性和实际品质；
- **兵器：** 看材质、承载能力、特性、来历和实际战绩；
- **阵法：** 看用途、覆盖范围、运行条件、消耗和维持成本；
- **血脉：** 前期不设统一品阶，以具体能力、觉醒条件和代价呈现；
- **源性事物：** 不设普通等级，不进入日常交易品阶。

## 二、前期三个境界

### 养元

修士吸收经过本世界山川与生命过滤的灵气，以功法炼成带有自身生命特征的元力，并逐步淬炼肉身、经脉与承载能力。元力主要留存在血肉和经脉中，可贯入拳脚、兵器或基础术法。

养元一至九重是前期最直观刻度，综合反映可稳定容纳的元力、经脉承载、炼化效率与控制程度，不等同于九个自动赠送技能的关卡。同重胜负仍取决于底子、手段、装备与判断。

### 灵轮

修士在体内建立相对稳定的元力周转，不再只靠“吸收—储存—耗尽”的一次性循环。灵轮能够回收部分散逸元力，提高持续输出和恢复效率，但仍需要外部输入，不是永动机。

前期只需让读者看清：灵轮修士能更稳定地让元力离体、连续使用术法并维持护身。灵轮是建立在肉身、经脉与功法运行中的周转结构，不是在丹田里凭空凝成一颗能量球，也不会因为建立回路便自动拥有无限元力。

#### 灵轮一至九重【已确认，可微调表现】

灵轮一至九重表示周转结构从初成到圆满的九个稳定层级，主要差别体现在循环承载、持续输出、离体距离、恢复效率与复杂战技负荷。它们不是九只实体轮，也不会每升一重自动得到一门技能。

- 灵轮一至三重：灵轮初成，能够稳定循环并支持常规离体元力；
- 灵轮四至六重：循环与身体结合更深，可以承担持续护身、较长战斗和更复杂战技；
- 灵轮七至九重：灵轮接近圆满，能够在高负荷下维持多段输出，是区域宗派灵轮弟子中的真正强手。

北山死境被区域宗派稳定后，可以出现从灵轮低重到高重的弟子。宁渊仍在养元时不能靠一次机缘正面击败灵轮高重；他的价值应来自先行路线、环境判断、队伍协作和尚未确定的有限特殊优势。

#### 灵轮突破最小规则【已确认，可微调】

第一卷和前期常规修士统一使用以下最小突破口径；建立灵轮即进入灵轮一重，后续再按一至九重积累，不额外扩写轮数或复杂仪式。

**一、突破前置**

1. 修士必须先稳定完成养元九重，且肉身、主要经脉、元力容量和控制达到所修功法建立灵轮所需的最低承载线；同为养元九重者仍可有明显强弱差异，残核、丹药或生死压力不能让人物跳过这一前置；
2. 所修功法必须包含一条完整的回返接口，修士已经能够让主要行气路线连续周转，只差把散开的末端接成稳定闭环；普通完整养元法可以提供普通接口，不需要天命传承；
3. 突破时必须有一份可追踪、与功法和身体基本适配的持续输入，用来启动循环、弥补最初损耗；输入可以来自灵地、药物或处理过的修炼资源，但不能来自无来源灌顶；
4. 未愈重伤、经脉灼裂或严重元力紊乱会显著提高失败风险。危机可以迫使人物当场尝试，却不能代替此前积累。

**二、最小过程**

> 聚元 → 接返 → 成环 → 稳轮。

- **聚元：** 把养元期分散留在血肉与经脉中的元力收束进已经练熟的主要路线；
- **接返：** 以外部输入补偿损耗，在主动控制下把一次性运行的末端接回起点，同时排出废热与驳杂残余；
- **成环：** 元力第一次完成闭合周转，散出的部分开始沿回路返回，而不是全部耗散；
- **稳轮：** 逐步撤去启动时的强推与外部输入，使回路在呼吸、动作和短时外放中仍不立即崩散。

**三、成功判据**

以下三项必须同时成立，才算真正建立灵轮：

1. 启动输入减弱或暂停后，主回路仍能自行连续周转，不需要修士逐段强推；
2. 呼吸、移动或一次受控发力改变身体状态时，回路不会立刻断开或逆行；
3. 修士能够完成一次受控的元力离体、术法或护身输出，并回收其中一部分可回收散逸，随后仍保有继续行动的能力。

成功只代表周转结构成立。新成灵轮可以立刻工作，却较脆弱；过度榨取会造成回路受损、短时停转或明显失稳，必须在后续静养和正常修炼中逐步稳定。这些后续损伤不默认抹去已经成立的境界；若要出现断轮或跌境，必须作为明确重伤另行结算。灵轮提高持续作战、恢复和控制，不自动使元力总量、单击威力与术法数量成倍增长。

**四、失败与代价**

- **闭环前主动中止：** 启动资源已经消耗，经脉出现数日以上的滞涩、胀痛和控制下降；伤势恢复后可以重试，但不能当场无代价再来一次；
- **闭环后强行续冲失败：** 回返路线撕裂或元力逆行，可能失去部分已经稳定的养元积累，恢复以数周或更久计算；反复强冲可能留下长期承载缺口；
- **使用不适配输入硬压：** 除上述损伤外，还可能留下无法正常排出的异质残余或循环偏差。越陌生、越高层的输入，风险越大。

普通失败不默认死亡或永久废掉，但每次失败都必须实际消耗资源、时间与身体状态。

**五、与祖源残核的边界**

残核不能替宁渊完成养元九重、生成回返路线、控制闭环或抹除失败代价。旧“择一保真、定源痕、环岳换位”方案已经否定，不再进入通用修炼体系。宁渊在第一卷第80—100章建立灵轮，仍必须满足本节全部前置；残核最终能否提供辅助以及辅助到哪一步，等核心发动机重新确认后再写入分卷合同。

### 神通

修士把长期修炼的力量性质、术法经验和个人理解固定进自身循环，形成具有个人特征、能够反复发动并继续成长的能力。神通不是随机觉醒，也不是到境界自动领取。

神通之后的境界、寿命和跨界规则均【暂不处理】。

## 三、人类与妖兽的对应等级

### 1. 总体口径

【已确认，可微调】人类修士使用境界名与境内重数，妖兽使用一至九阶：

| 妖兽等级 | 常规对应修士 | 当前处理 |
|---|---|---|
| 一阶妖兽 | 养元境 | 前期主要活动层级，需要明确使用 |
| 二阶妖兽 | 灵轮境 | 可作为前期明显上限与重大威胁，内部细分待设计 |
| 三阶妖兽 | 神通境 | 暂只保留概念接口 |
| 四至九阶妖兽 | 对应后续大境界 | 只保留九阶总框架，不提前创造境界名称与生态百科 |

一至九阶是妖兽生命层次和常规威胁的纵向尺度，不是让丹药、功法、兵器和阵法一起套用的万能九级表。

### 2. 一阶妖兽的前期细分

为方便养元阶段实战判断，一阶妖兽暂按初段、中段、后段区分：

| 一阶细分 | 常规对应 |
|---|---|
| 一阶初段 | 养元一至三重 |
| 一阶中段 | 养元四至六重 |
| 一阶后段 | 养元七至九重 |

这种对应表示通常正面威胁，不是绝对胜负公式。妖兽肉身、速度、毒性、天赋与环境优势，修士的功法、兵器、术法、准备和配合，都会改变结果。受伤、幼年、返性、畸变与异常污染也必须单独计算。

### 3. 妖兽、灵兽与异兽

【已确认，可微调】三种称呼不建立三套等级：

- **妖兽：** 野外具有超凡力量、对人存在潜在威胁的兽类，是前期最常用总称；
- **灵兽：** 被驯养、契约，或性情相对稳定、能够与人长期共处的兽类；
- **异兽：** 出现返性、畸变、陌生古性或其他特殊变化的描述性称呼，不是独立生命等级。

三者共用一至九阶。某只兽可以因处境被不同人物称为妖兽或灵兽，但不会因此改变阶位。

### 4. 其他体系如何保持直观

- **功法：** 可用基础法、家传法、宗门真传、古法残篇等社会称呼，同时必须说明适用环境、传承完整度和修炼上限；
- **术法：** 可用基础术法、上乘术法、秘术、神通等粗略称呼，实际强弱仍看消耗、条件、掌握和效果；
- **丹药与药材：** 以用途为先，同一种资源可按药性和成色称次品、合格、上等，不将所有丹药统一套入九阶；
- **兵器：** 前期可用凡兵、灵兵、古器等通俗分类。凡兵、灵兵重在承载与特性，古器重在来历与时代条件，古器不保证当前一定更强；
- **阵法：** 以用途、覆盖范围、运行条件、消耗和维护成本判断，不急设统一品阶；
- **源性事物：** 不进入日常等级表，祖源残核不能被称为普通“九阶宝物”或“源级神器”。

这些称呼为读者提供快速印象，但正文最终要以实际表现校正标签。

## 四、特殊转换能力进入修炼体系的接口

任何能够处理源性、异质或不适配输入的特殊器物，都不能绕过本文件的通用规则：

1. 必须有现实输入，输出少于有效输入，并产生损耗、废质或承载压力；
2. 每次作用必须有明确触发条件、单一主要结果和失败可能，不能把一次输入拆成多份无成本保留；
3. 输出不自动等于修为；源性或异质输入不能无视低阶身体、功法和本世界规则直接灌入；
4. 特殊器物不能让空白载体凭空长出与输入无关的新术法；
5. 低阶修士不能仅凭肉身或基础功法直接吞纳过纯输出；
6. 特殊器物不能自动提示、发布任务、替代修炼、代打或无条件护主；
7. 触发条件、选择过程、单次容量、恢复和超限后果必须能够在场景中验证；
8. 个别器物的具体输入、输出和首次效果，不在本文件定义。

祖源残核的正面功能仍【暂停】【待重新设计】。旧“择一保真、可行流路、定源痕”不属于本体系；新方案确认后再写入分卷合同。

## 五、仍待设计的通用规则

1. 灵轮一至九重的具体资源量级、不同功法表现与同重比较方式；突破前置、最低成功判据和失败代价已经确认；
2. 神通境的最低形成条件、能力边界与同境比较方式；
3. 二阶、三阶妖兽是否需要与对应人类境界一致的段位细分；
4. 四至九阶妖兽与后续大境界的对应；
5. 灵魂力量正式进入修炼体系的阶段与通用边界；
6. 炼药、阵法、炼器等道路如何与境界形成清楚但不机械的接口。
