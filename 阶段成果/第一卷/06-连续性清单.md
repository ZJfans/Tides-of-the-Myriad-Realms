# 第一卷连续性清单（玄幻化重构版）

> 状态：【使用中，可随章纲微调】硬性边界；【候选】【待验证】时间、资源名称、残核使用次数、魏氏人物结局与沉岳古墟细节。
>
> 【局部失效】修为、残核、认知与北山事故边界继续有效；府、镇、武院、镇岳司、四府与东垣路线等地图旧称暂停使用，等待新版故事骨架后重建。

## 一、第一卷硬性边界

- 宁渊开篇已经能够修炼，处于养元阶段，不是废柴；
- 第一卷结束建立灵轮，但残核不能直接灌境；
- 前期异常局部、微弱且早于传统推算，不宣布天下回潮；
- 东衡仍有正常家族、宗门、武院、城镇和修炼秩序；
- 魏氏依靠灵地、强者、族兵、功法和宗门关系形成压力，不靠现代商业程序；
- 残核不创造能量，只转换特定节点中的混杂微力；
- 第一卷不解释祖河、九潮、截流、东衡失陆和异族完整真相；
- 沉岳古墟只被人物理解为古代秘地、封禁内景或空间灾变；“寂白坠境”仅为作者后台候选；
- 第一卷全部位于东衡，“东行资格”只通往东垣其他府域，不是跨大陆名额；
- 宁家不是远古守护家族，宁川不是隐藏强者；
- 第一异族不作为第一卷公开反派。

## 二、时间与路程

第一卷建议跨度两至四个月，不锁死具体历法。

| 阶段 | 建议耗时 | 连续性要求 |
|---|---:|---|
| 1—8章 | 2天 | 开禁、争牌与入山连续发生 |
| 9—31章 | 4—6天 | 七日猎会倒计时不能被遗忘 |
| 32—45章 | 7—10天 | 养伤、战功校验与青岚猎会 |
| 46—60章 | 3—5天 | 魏氏试禁与北山夜变紧密相连 |
| 61—72章 | 5—8天 | 青岚到临河约三至五日，受验不能当天全部完成 |
| 73—96章 | 3—5周 | 猎榜、灵池修炼和沉岳古印复苏 |
| 97—110章 | 7—12天 | 四府队伍集结与沉岳台试炼 |
| 111—125章 | 1—2天＋善后 | 沉岳古墟保持连续压迫感 |

路程参考：

- 青岚到北驿：镇北缘，当日可达；
- 北驿到北山开放区：约两日山路；
- 开放区到雾谷边缘：数个时辰至一日，随旧路状态变化；
- 青岚到临河府：约三至五日；
- 临河到沉岳台：半日至一日【候选】。

写作纪律：

1. 每次成功必须让读者看见能量输入；
2. 残核只负责有限转换，不同时承担寻宝、疗伤、储物、推演和鉴定；
3. 宁渊只能从身体反应总结规律，没有面板和器灵说明；
4. 转换收益必须立即用于场景行动，不能储存多年；
5. 突破灵轮的主体必须是宁渊自身修炼积累。

## 八、人物关系进度

### 宁渊—宁川

- 卷初：宁川反对进入雾谷，但不阻止宁渊争入山牌；
- 北山夜变：宁川只提供一次有限经验，不能代替宁渊行动；
- 卷末：宁川承认七年前也听过石中水声，完整真相仍未说出。

### 宁渊—岳小满

- 从临时队友建立山地默契；
- 在是否越线、是否放弃排名上有真实分歧；
- 临河阶段可以短暂分队；
- 第一卷不锁定恋爱关系。

### 宁渊—周砺

- 周砺认为宁渊判断敏锐但容易为少数人改变整体计划；
- 宁渊认为周砺过早接受牺牲外围；
- 两条路线都要在北山夜变和沉岳古墟中证明价值；
- 卷末成为长期竞争者，而非追随者。

### 宁渊—苏见微

- 从灵药与古印异常开始合作；
- 苏见微不因为宁渊有主角光环就相信其判断；
- 她负责药性和生机判断，不负责解释祖源百科；
- 感情方向保持候选。

### 宁渊—裴行素

- 裴行素认可战功，也追究越线；
- 他能制衡普通魏氏子弟，无法随意扳倒魏承谷；
- 卷末根据实际行动推荐宁渊，不做无条件贵人。

## 九、魏氏敌对连续性

### 魏骧

- 第1章：因阵钉反应注意宁渊；
- 9—19章：把弱队用于驱赶兽群；
- 20—31章：先夺古印并索取宁渊残片；
- 32—45章：仍取得猎会第一，保留压迫感；
- 61—96章：依靠家族资源和自身天赋持续领先；
- 97—123章：为家族夺取古墟灵物并封路，最终与宁渊决战。

### 魏承谷

- 30章前后：以家族旧规向青岚施压；
- 46—60章：私开雾谷外阵造成北山夜变；
- 89—110章：以沉岳古印推动提前开启试炼深层；
- 111—124章：控制出口、优先保魏氏核心，阶段责任暴露；
- 卷末只削弱其权力或令其退场，不灭魏氏全族。

### 魏氏内部

不能人人都是恶人：

- 有族人真心认为魏氏镇守北山，因此有权优先取得传承；
- 有年轻人只想通过试炼；
- 有族老反对魏承谷冒险，却不愿公开削弱家族；
- 卷末可由内部切割魏承谷，体现大族自保能力。

## 十一、沉岳古墟写作边界【候选】【待验证】

- 只坠入一角残破地域，不是完整新大陆压到临河；
- 视觉必须与东衡明显不同，但不在第一卷建立完整异世界百科；
- 危险主要来自地貌错位、恢复困难、残存生物和出口争夺；
- 不写规则怪谈式即死条款；
- 不让土地日常消失成为东衡常态；
- 古墟遗物只能少量带出，不能让临河人人暴富；
- 其出现证明变化不止资源复苏，也涉及空间稳定，但人物不能直接推出失陆真相。

## 十二、每章检查项

1. 宁渊本章要争什么具体资源、资格、生路或人物？
2. 阻碍是否来自修为差距、势力占有、危险环境或合理人物选择？
3. 本章是否改变了战利品、名额、伤势、关系或认知中的至少一项？
4. 是否连续三章只在谈势力，没有修炼、行动或战斗？
5. 魏氏是否在做符合家族目标的事，而非围着宁渊无故找茬？
6. 残核出现时是否交代输入、输出、代价和不可重复原因？
7. 人物是否说出超越自身认知层级的真相？
8. 章末问题是否具体，避免“风暴才刚刚开始”等空话？

## 十三、卷末状态

- 宁渊：建立灵轮，仍有经脉伤；取得东垣内部东行资格，只掌握残核极少规律；
- 宁川：旧伤阶段缓解，留在青岚，七年前经历未完全公开；
- 岳小满：成为可靠行动伙伴，是否东行待定；
- 周砺：保住武院核心位置并取得东垣内部东行资格；
- 苏见微：确认异常生机与古墟值得追查，是否同行待定；
- 裴行素：成为有限可信的府级行动者；
- 魏骧：败于宁渊，生死待定；
- 魏承谷：责任暴露，具体退场方式待定；
- 临河魏氏：失去部分北山与沉岳台权力，仍是地方大族；
- 栖岳宗别院：开始正式关注宁渊和异常古墟；
- 青岚／北山：进入限制开放与争夺新阶段，没有被宁渊修复；
- 读者：确认变化不止北山一处，仍不知道东衡失陆和祖河真相。
