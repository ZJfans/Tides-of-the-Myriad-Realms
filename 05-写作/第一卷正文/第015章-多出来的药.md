# 第十五章 多出来的药

陶管事没有再叫人进畦。

他把空筐放回墙外，取出旧图，展在一块干石上。图上东坡各处药田画得很清楚，最上面那片废畦仍留着魏家的记号，墨色比其余地方淡些，却没有划掉。

“这是原来划的地。地荒了，魏家没退回门里，年年仍留人在这儿。”

赵观山看过图，道：“我知道这是魏家的地。可这里突然出了水，药也重新长起来，得请柳师叔看过，才能决定怎么采。今天先取样，别把根起光。”

“留几株给他看就是。熟药不采，药性走了，算谁的？”

罗苓蹲在墙边，将药叶翻到背面。银点不在平常的位置上，叶筋附近尤其密，边缘却稀。她拿出从下坡采来的叶，放在旁边，叫陶管事自己比。

“都是青髓藤，长出来的样子已经不同。谁能保证它正好熟了？”

陶管事没有接这句话，转头看向山下。

魏承礼沿石阶走上来，腰间配剑，袖口束得很紧。他脚步不快，走到墙前先看水，再看魏骧，最后才向赵观山见礼。

“赵执事。我是魏承礼，今日跟陶管事来核东坡药根。”

魏骧从石上拿起旧图，递给他。

“是废畦里新长出的藤。罗师姐看着和下坡的不大一样，还没弄清是什么缘故。”

魏承礼低头看图，问罗苓可否只取边缘几株，把中间药性最足的一带留下。他想保住中央那丛长得最好的药藤，留待家中来人细看。

罗苓指了指中央一丛阔叶。

“越是与别处不同，越要取。只带瘦的回去，怎么知道里面长成了什么？”

魏承礼看了她一眼，没有立即争。

“那两边一起取，各带一份回去验。起根的位置也留下记号，方便回来复看。”

赵观山应下，让两边各自备好药匣。

罗苓带宁渊与周砺入畦取样，陆昭在缺口接匣。外缘那株起出时，宁渊看清白须竟从干裂的旧皮下生出，贴着石缝伸展；下坡成熟药根的须子微黄，远没有这样的青光。

他照罗苓的指点留住根周原土，托起完整样本。湿土冰凉，腹中元力却在靠近它时轻轻躁动。宁渊不敢引那股气，只想尽快让柳师叔看看，这些枯根究竟如何又活了。

就在宁渊托起根团时，魏承礼走近，俯身查看。他带来一只魏家的药匣，示意宁渊往这边放。

“这一株挖得完整。”魏承礼道，“先放我们这只匣吧，我带回族里验过，省得两边都折腾。”

宁渊抬头望向罗苓。

罗苓正在几步外查看中央药藤，赵观山也在她身侧。取样前说好分存，宁渊这一株标的是石灯门，没有临时改过。

“这一株说好是带回门里的，要放在那只匣子里。”他指向陆昭。

魏承礼笑了一下。

“换一株给她也是一样。我这只先空着，耽误不了你的差事。”

他伸手来托，动作很自然，仿佛只是替人分担重量。宁渊手臂一沉，根团下的布被压住，若此刻往回夺，白须就可能折断。

宁渊挪到干石上站稳，仍托着根团，扬声叫罗苓：“罗师姐，魏家要把这株带回去，您过来看一下。”

声音一出，缺口旁的陆昭立刻转头。

魏承礼的手停了一瞬，随即放开。

“我只是想看清楚些，你先放过去吧。”

宁渊肩背绷着，没有接话。直到罗苓过来，确认仍放原匣，他才慢慢把泥团交出去。右臂酸得发热，掌心有几个被碎石硌出的印，但药根没有断。

陆昭盖好匣，低声问他没事吧。

宁渊说没事，将手收回来。陆昭还没扣紧匣盖，罗苓忽然俯下身去，宁渊顺着她的目光看，发现方才露出的白须末端，青色竟已淡了一点。

药根离土不过片刻，便有了这样的变化。

罗苓让人立即记下变化，又对过起根的时辰，免得回山后记不清间隔。魏承礼站在旁边，脸上的笑意淡了些，没有再伸手。

随后取中央那株，争执又起。

陶管事说这里上月才清过一次枯根，眼前的新藤未必是旧地回生，也可能是漏下的苗恰好长好。他说话时，看山老人正蹲在缺口修正石槽，手上动作忽然停了一下。

赵观山看见了。

“上月清过？”他问老人。

老人先望陶管事，嘴唇动了动。

魏承礼在一旁接话：“老伯每日管几片坡，日子未必都记得。先采样吧。”

宁渊记得老人方才说过，上月只来捡过架子。如果那时没有翻土，也没人补种，这批藤就是从荒着的旧根上自己长回来的，不能算成近来栽下的药苗。

老人把石槽放好，擦了擦手。

“没清根。只捡了坏架子。”

陶管事皱眉：“你再想想，工棚那边报的是清地。”

“报什么我不晓得。我带两个人，搬了四捆竹架下去，土没翻过。”

这回老人说得清楚，眼睛却一直没抬。宁渊看着老人，想起他还要在这里做工，不禁担心陶管事以后会不会为难他。

赵观山没有在这里审账，只让罗苓将实际所见记下，连旧架断口、根下新须一并带图回去。养护如何记，是两边管事回头查的事，眼前不能因此把药性变化说成已经明白。

魏承礼收起旧图，转向魏骧。

“十二叔管这里多年，秋后要交药。今日原来的药根已轻了许多，再封一片，回去怎么说？”

魏骧一直在看那道新水，此刻才抬头。

“把新水和药藤的事一起报回去，十二叔也得知道这里的变化。”

“你今年要成轮，家里哪处供给不紧？留在这里等，灵药也不会自己进库。”

宁渊站得不远，想起魏骧说过，家里已经替他备好了成轮用的药。可往后还有补养，还有魏承礼等着，药山少收一批，家里便得从别处填。

魏骧低头看着湿土里的新须。药根一旦起出，能不能再养回去，连罗苓也没有把握。

“若真是废畦重新能养药了，往后收成会比现在多。先查清楚再采，我会回去同十二叔解释。”

魏承礼看着他。

“那你替家里争什么？”

“原约还在，地没有送出去。我会请十二叔带养护的记录来，亲自同柳师叔说。魏家这些年真做过的，不会因为今天出了水就不算。”

他说完，又把图要了回来，指着坡下的两片成熟药畦，向赵观山提出照原份额先交付那里的药，不与新发现混在一起。赵观山同意了，也没有要求魏家把现成所得一并留着。

魏承礼没再拦。他走到陶管事身旁低声说了几句，叫人把魏家应取的药装好，又让一名熟悉山路的伙计先回去报信。

伙计很快下山去了。宁渊转回身，帮罗苓将取样的几处标在图上，又补记了渗水的位置。

罗苓最终取了三处药株与少量土水，双方分存。中央那株只起外围一支，保留主根继续观察。其余废畦暂缓采掘，两边各留看守，等柳师叔与魏家负责此地的人同来。

样本由罗苓带回，六人的正常药份另收。看山老人仍留在沟边修旧水槽，宁渊经过时向他道谢，老人只是点点头，又弯下腰去。陶管事已经往棚屋走了，老人一直没抬头看他。

下山前，魏骧走过来，说方才承礼想先拿样本的事，自己看见了。

“这一株既然说好归门里，他就不该擅自来拿。”

“说好了两边分存，他一上来就要拿走，我怕药根被扯断，又不能往回拉。”宁渊说起此事仍有些恼火。

魏骧说自己会和承礼谈，随后去搬自家的药箱。宁渊仍有些恼，直到陆昭叫他，才松开揉着掌心的手。

陆昭过来问宁渊手臂还酸不酸。宁渊摇头，望着魏承礼下坡的背影。对方没有拔剑，只借着接药伸了一次手，就险些把分好的东西改了归属。

“下回他再来拿，我替你看着。”陆昭说。

“先把话说明白。若他还拿，我们一起叫人。”宁渊把药篓提上肩，“也得练刀。不能每次都只剩叫人的办法。”

走上山脊，罗苓又打开药箱看了一次。青髓藤离土后叶光渐淡，湿土里的白须却仍有微光，她让人加快脚步，说要趁这个变化还在，赶回去给柳师叔看。

赵观山点头，队伍不再停留。

夕阳落在青岚城的方向，药山渐渐沉进他们身后的阴影。宁渊回头，只见灰白山坡间露着一点青，原先干涸的旧槽里，新水仍在往下流。

宁渊想把这件事告诉父亲，又怕父亲高兴得太早。罗苓在前面催了一声，他收回目光，加快脚步追上去。
