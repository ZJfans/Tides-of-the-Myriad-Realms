# 《诸天回潮》第三卷章纲：071—100

> 本卷逐条候选，尚无正文。卷内骨架与唯一章纲合并；当前正文进度、跨卷时间和回报见[前百章总览](../00-前百章总览.md)。

求师与寻亲把朋友带到更广世界，两条有真实收益的道路发生冲突；宁渊成轮入宗，陆昭选择自己的查证方向。

| 章段 | 主线转折 |
|---|---|
| 071—079 | 【候选】山外见识与师承吸引；宁陆从不同知识获得检视合作机会，陆倾向更快的感知提示，宁尝试学习普通识读。 |
| 080—088 | 【候选】宁陆以不同知识参与旧器检视，资料误判引发险情；预警救友与感官误导同场，朋友选择不同的下一步。 |
| 089—095 | 【候选】休养积累后成轮，争取明确刀修师承，几场有区别的交手兑现成长。 |
| 096—100 | 【候选】医师返城提供有限证词，许交清合作旧单，普通图本进入下一阶段学习；朋友与家庭均有回报，新生活开启。 |
